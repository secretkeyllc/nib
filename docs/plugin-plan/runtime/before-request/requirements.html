before-request · Requirements

Rewriting at the model request layer has been withdrawn. This page keeps the withdrawal decision and provides the scenario migration table: each thing that was once wanted has a better home.

status: draft · issue #561 · permission runtime.request.before · withdrawn · reopening message_list rewriting is not offered as an option

Scope Verified

  • Scope: the former "rewrite the request body before a model request goes out" tier of capability - now withdrawn.
  • This page does two things only: confirm that the withdrawal stands, and provide the scenario migration table.
  • Not covered: how rewriting would be implemented, how it could be reopened, or how message_list would be edited.

Current state (code-verified) Verified

  • The withdrawal is a product decision: ADR 0303 (formerly 0295) records a decision that was later taken back; implementation did not fall behind.
  • The core event mapping is not exposed: runtime.request.before is marked withdrawn in the permission list, and the trusted runner rejects that event.
  • Reopening is not scheduled: this round does not write up "message_list rewriting may be reopened" as an option.
  • Sandbox gap: the wiring channel for sandbox plugins (ADR 0300) does not exist yet - registration, budgets, and circuit breakers are all missing. Barely relevant here - this page itself is withdrawn.

Decisions this round TBD

There is exactly one decision this round: the withdrawal stands. To overturn it, three questions must be answered first: what auditing records, how long the budget is, and how the user learns that the request was changed.

Explicit non-goals Verified

  • Plugins may not rewrite the model request body (message_list, the tool list, or the system prompt).
  • Reopening message_list rewriting is not written up as an option.
  • No silent rewriting - any rewrite must be auditable and perceivable by the user; the current choice is to not offer it at all.
  • No implementation details are designed in this folder.

Open questions Open

  • None - the decision this round is simply to keep the withdrawal.
  • If it is reopened later, the prerequisites are undecided: audit fields, a request-level budget, and user visibility. The wiring channel for sandbox plugins (ADR 0300) does not exist yet - registration, budgets, and circuit breakers are all missing.
