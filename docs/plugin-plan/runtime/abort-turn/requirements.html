abort-turn · Requirements

A plugin can request an abort of the running turn. No input, and the return says whether the request was accepted. Risk high, confirmed at install time.

status: draft · issue #561 · permission runtime.turn.abort · risk high

Scope Verified

  • Covers one thing only: "request an abort of the turn currently running".
  • Not covered: pre-send interception (before-send), queue withdrawal (composer), session deletion (session-lifecycle).

Explicit non-goals Verified

  • A plugin may not fabricate an abort reason or pretend the user pressed stop.
  • No silent aborts - a refusal returns false and records a diagnostic.
  • No aborting other sessions - this only targets the current turn.
  • No handling of queued messages (that is the queue's job).

Open questions Open

  • Whether to carry a user-readable reason; whether to distinguish abort scope.
  • The wiring channel for sandbox plugins (ADR 0300) does not exist yet - registration, budgets, and circuit breakers are all missing.
