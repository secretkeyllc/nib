Life of an abort

momentwhat happens
CallThe plugin issues an abort request (no reason, no scope)
GatingNo permission → false plus a diagnostic; with permission it continues
AcceptedThe host stops the current turn: no further model requests, and tool calls are wrapped up as far as possible
Returntrue / false goes back to the plugin
