turn-continue · Requirements

A plugin continues a turn on its own initiative: it enqueues a message and the host runs a turn from the queue. The message carries plugin attribution, so the user can see it.

status: draft · issue #561 · permission runtime.turn.continue · goes through queuePush · plugin attribution visible

Scope Verified

  • Only "a plugin enqueues a continuation on its own initiative": one message enters the host queue, and one turn runs from the queue.
  • Out of scope: the passive end-of-turn query (turn-closing), aborting (abort-turn), intercepting before send (before-send).

Current state (code-verified) Verified

  • The plugin side is implemented + e2e: permission runtime.turn.continue, enqueued through the host queue session.queuePush with the plugin as source.

  • Attribution is persisted: a queued turn is a visible row attributed to the plugin - the host fills in pluginId / pluginLabel, and a plugin cannot forge them.
  • No quota: deliberately no upper limit today (ADR 0303 (formerly 0295)) - the controls are attribution + visibility + the user being able to stop at any time.
  • Same name, different thing: the core's internal continuation path is unrelated to this API; the end-of-turn continuation goes through agent.steer, and that path currently lacks attribution (see turn-closing).
  • Sandbox gap: the wiring channel for sandbox plugins (ADR 0300) does not exist yet - registration, budgets, and circuit breakers are all missing.
What it stands on: visible attribution. A plugin can spend the user's money to make the host keep running - the trade is that every turn appears in the conversation in the plugin's name, so the user can see it and can stop it. The path with attribution is queuePush.

Explicit non-goals Verified

  • No unattributed / hidden continuation turns - visibility is the precondition for this API existing.
  • A plugin may not impersonate the user when posting a message - the attribution is always the plugin.
  • Plugins may not rewrite message rows that already exist.
  • No silent injection.
