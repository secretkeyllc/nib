turn-recap · Requirements

Read a recap: the facts of this turn, or (with permission) the most recent message rows in the session. Pull-style - the plugin calls it on its own initiative.

status: draft · issue #561 · permission runtime.turn.recap · the session scope also needs runtime.session.read

Scope Verified

  • Only "read a recap": the factual summary of this turn, or the most recent message rows in the session.
  • Out of scope: live events (turn-watch), structured facts (turn-facts), compaction (session-lifecycle).
