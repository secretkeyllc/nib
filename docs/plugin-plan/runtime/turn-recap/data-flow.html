1API contract Proposal

A headless interface, runtime.turn.recap (high). Pull-style: the plugin asks, the host answers, nothing is pushed.

// 只读这一轮的事实（无正文）
const r = await pi.recap({ scope: "turn" });

// 会话范围：最近消息行（需另授 runtime.session.read）
const s = await pi.recap({ scope: "session" });
