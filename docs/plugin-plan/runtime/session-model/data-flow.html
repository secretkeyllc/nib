1API contract

pi.session.getModel(): Promise<{ sessionId: string; modelKey: string | null; thinkingLevel: string | null; providerId?: string; modelId?: string }>

Reads the model snapshot bound to the current session. Permission session.read (reused; read-only, does not raise the privilege).

Input

None.

Output

fieldtypenotes
sessionIdstringThe id of the session this snapshot belongs to; used to pair with the session:modelChanged event.
modelKeystring | nullprovider/model; null when there is no session or nothing is bound.
thinkingLevelstring | nullThe current thinking level; null when unset.
providerIdstring | undefinedConvenience field split out of modelKey.
modelIdstring | undefinedConvenience field split out of modelKey.

Input example

// 无入参
pi.session.getModel()

Output example

{
  "sessionId": "s_01J8",
  "modelKey": "anthropic/claude-sonnet-4-5",
  "thinkingLevel": "medium",
  "providerId": "anthropic",
  "modelId": "claude-sonnet-4-5"
}
Boundary in one sentence. It is a read-only snapshot and does not provide model changes; use it together with session:modelChanged - the event pushes changes, this method fetches the snapshot. With no active session, modelKey / thinkingLevel are null rather than an error.

2How data flows

  1. Call. The plugin calls it with no arguments.
  2. Validate. The main process checks the session.read permission.
  3. Execute. The host reads the current session's model binding and thinking level (session state, no IO).
  4. Return. Everything comes back at once; no subscription, no streaming.
directioncontent
plugin → hostNone (pure query).
host → pluginThe model snapshot (sessionId + modelKey + thinkingLevel + the breakdown).
