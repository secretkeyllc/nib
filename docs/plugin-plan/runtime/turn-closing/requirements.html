turn-closing · Requirements

A passive query at turn end: a plugin can suggest a few more rounds. The continuation is injected through agent.steer({role:"user"}) - with no plugin attribution. That is a defect and must not be written as "attribution visible".

status: draft · issue #561 · permission runtime.turn.closing · continuation goes through agent.steer · plugin attribution missing (defect)

Scope Verified

  • Only "the passive query before a turn closes": a plugin may suggest a continuation.
  • Out of scope: a plugin actively continuing (turn-continue), live observation (turn-watch), aborting (abort-turn).
  • It must be stated: the continuation path lacks attribution - this is a defect, not a feature.

Current state (code-verified) Verified

  • The budget already exists: at most a few continuation rounds per run (currently 4); a continuation injects one message by default and enters the loop through agent.steer({role:"user"}).
    feat/528-plugin-slots@ · packages/agent-runtime/src/extensions/turn-closing.ts · continuation budget / default injection
    feat/528-plugin-slots@ · packages/agent-runtime/src/runtime.ts · agent.steer continuation
  • The continuation path lacks plugin attribution (defect): the message injected by agent.steer({role:"user"}) carries no pluginId / pluginLabel - the user cannot tell that a plugin caused the run. Compare: turn-continue → queuePush does add attribution. The two are inconsistent.
  • Already emitted, few consumers: the event is wired up; the SDK's typed payload is still thin.
  • Sandbox gap: the wiring channel for sandbox plugins (ADR 0300) does not exist yet - registration, budgets, and circuit breakers are all missing.
Defect: the continuation path lacks attribution. It is not "attribution visible". The user message injected by steer has no plugin name; what does have attribution is turn-continue's queuePush. How to close it is in the decisions.

Explicit non-goals Verified

  • Do not describe an unattributed continuation as "attribution visible" - that is a defect description, not a capability description.
  • Plugins may not edit the conversation record or fabricate turns - a continuation goes through agent.steer into the normal loop, and the rows are recorded by the host (though currently without a plugin name).
  • No unbounded continuation - there is a budget.
  • No write permission for plugins at turn end.
