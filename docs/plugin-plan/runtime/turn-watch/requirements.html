turn-watch · Requirements

The read-only event stream of one run. A plugin can listen to 12 events and change nothing at all. fire-and-forget: no timeout, no receipt, no re-delivery.

status: draft · issue #561 · permission runtime.turn.watch · risk medium · 12 core events

Scope Verified

  • One run from agent_start to agent_settled / agent_end: its read-only event stream, 12 events in total.
  • Out of scope: reading message bodies (that is turn-recap), the write path (there is none), and interception (that is tool-gate / before-send).

Explicit non-goals Verified

  • Plugins may not change events, messages or tool results - it is read-only.
  • No delivery guarantee - fire-and-forget; lose one and it is gone.
  • No receipts, re-delivery or timeouts (non-result).
  • No message bodies - for those, use runtime.turn.recap.

Open questions Open
