tool-gate · Data flow

The path of the two hooks before and after a tool call. Six fixed sections: API contract / How data flows / Error handling / What is not provided / Related entries / Open questions.

status: draft · issue #561 · permission runtime.tool.gate · budget 30s · changing arguments permanently excluded

1API contract Proposal

Headless result-style events: tool_call / tool_result → runtime.tool.gate. 30-second budget, timeout = no opinion.

// 调用前：可拦下，不能改参数
pi.on("tool_call", async (ev) => {
  if (isDangerous(ev.toolName)) {
    return { action: "handled", reason: "该工具会写入危险路径，已拦下" };
  }
  return { action: "continue" };
});

Life of one tool call

momentwhat happens
Before the callPlugins are asked in a chain; they may block; they cannot change arguments
TimeoutTreated as no opinion; the tool runs as usual
ExecutionThe host runs the tool
After the resultA result summary is delivered read-only; plugins cannot change the body
