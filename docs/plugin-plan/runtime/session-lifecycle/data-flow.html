1API contract Proposal

Headless event listening, runtime.session.lifecycle. Everything except before_compact is notification-style.

// 仅压缩前可否决
pi.on("session_before_compact", (payload) => {
  // payload: { type, reason, retentionMode,
  //           segment: { messages, messageCount, tokensBefore, retained } }
  if (needMoreTime(payload.segment)) {
    return { cancel: true };
  }
  return {}; // 或 { cancel: false } / 不返回
});

Life of a before_compact

momentwhat happens
Compaction about to startThe sidecar emits before_compact; the payload carries type, reason, retentionMode, segment
PluginReads segment; may return { cancel?: boolean }
cancel: trueThis compaction is cancelled; the content is retained
No cancel / timeoutCompaction continues; a compact or compact_failed notification follows
Only a compaction can be vetoed. Switching sessions, forking and deleting do not accept cancel.
