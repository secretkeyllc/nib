1API contract

onPanelInvoke?: (channel: string, payload: unknown) => Promise<unknown> | unknown  // PluginModule 可选钩子

The fixed-channel call entry point isolating a panel page from its plugin; panel capabilities do not grow through this hook, and no permission needs declaring. —

Input

fieldtyperequirednotes
channelstringYesThe channel name, defined by the plugin itself (a fixed channel, not general-purpose IPC).
payloadunknownYesData the panel page carries with the call; it may be empty, and the plugin defines its shape.

Output

fieldtypenotes
(return value)Promise<unknown> | unknownThe result, whose shape the plugin implementation decides, returned to the panel page unchanged.

Input example

// 宿主调用：转发面板页的固定通道调用
module.onPanelInvoke("submit", { title: "周报", count: 3 })

// 插件侧最小实现
onPanelInvoke(channel, payload) {
  if (channel === "submit") return { ok: true, saved: payload.title }
  throw new Error("未知通道: " + channel)
}

Output example

// 返回类型为 unknown，结构由插件实现自定义
{ "ok": true, "saved": "周报" }
Boundary in one sentence. It is not general-purpose IPC: the plugin defines the channel semantics, and the host never uses it to expose plugin.setSettings, fs.remove, or arbitrary Electron IPC.

2How data flows

  1. Call. While the panel is open (the isolated sandbox page opened by ui.openPanel), the panel page issues a call over the fixed channel.
  2. Forward. The host forwards the channel name and data to the plugin main module's onPanelInvoke; the panel page is sandboxed and never touches the plugin process directly.
  3. Execute. The plugin dispatches on channel, and the plugin defines the payload shape.
  4. Return. The result (possibly async) goes back to the panel page; an unhandled channel returns through the host error model.
directioncontent
host → pluginThe channel name and the payload data.
plugin → hostThe result, returned to the panel page unchanged.

3Error handling

No error codes. When no channel handles the call, the host error model is returned to the panel page.

4What is not provided

Not a general-purpose IPC; the plugin defines its own channels.

Host guarantees / accepted costs: Host guarantee: `plugin.setSettings`, `fs.remove`, and arbitrary Electron IPC are never exposed. Accepted cost: the plugin defines the channel itself.
