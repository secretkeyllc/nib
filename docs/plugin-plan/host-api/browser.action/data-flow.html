1Interface contract

pi.browser.action(input: { action: "back" | "forward" | "reload" | "stop" }): Promise<void>

Runs back / forward / reload / stop on this plugin's guest page. Permission: —.

Input

FieldTypeRequiredDescription
action"back" | "forward" | "reload" | "stop"YesBrowsing-action enum; exactly one of the four.

Output

FieldTypeDescription
(return value)voidNo output; the action is committed once Promise<void> resolves.

Input example

{ "action": "reload" }

Output example

// no output (Promise<void>)
Boundary in one line. Only affects the browsing history and loading state of this plugin's guest page; it cannot escape the guest page boundary.

2How data flows

  1. Call: the plugin runs pi.browser.action({ action: "reload" }).
  2. Validate: the host checks that action is one of back / forward / reload / stop.
  3. Execute: the host applies the browsing action to the guest page bound to this plugin's panel.
  4. Return: Promise<void> resolves with no value; the binding becomes invalid after the plugin unloads.
DirectionContent
plugin → hostAction enum (back / forward / reload / stop).
host → pluginNo returned data (Promise<void>).
