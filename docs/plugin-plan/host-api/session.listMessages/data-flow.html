1API contract

pi.session.listMessages(input: { sessionId: string; limit?: number; cursor?: string; order?: "asc" | "desc"; contentLimit?: number }): Promise<PluginSessionMessageListResult>

Reads messages of one of this plugin's sessions with pagination (role, body, tool calls), supporting ascending/descending order and per-message body truncation. Permission: —.

Input

FieldTypeRequiredNotes
sessionIdstringYesSession id owned by this plugin.
limitnumberNoMaximum number of messages per page.
cursorstringNoThe nextCursor returned by the previous page.
order"asc" | "desc"NoChronological ascending or descending order.
contentLimitnumberNoMaximum length of a single message body; anything beyond is truncated.

Output

FieldTypeNotes
itemsPluginSessionMessageResult[]Messages on this page. Array element shape: id, role ("user"|"assistant"|"tool"), content, contentTruncated? (true = body was truncated), createdAt, origin (always "external"), tool? (tool messages only: { name, callId, status: "success"|"error", args?, result? }).
nextCursorstringPresent when there is a next page; otherwise omitted.

Input example

{ "sessionId": "imp_9f3a2c", "limit": 50, "order": "asc", "contentLimit": 2000 }

Output example

{
  "items": [
    { "id": "m_01", "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z", "origin": "external" },
    { "id": "m_02", "role": "assistant", "content": "看起来是依赖版本冲突，先升级……", "contentTruncated": true, "createdAt": "2026-02-12T08:30:07.000Z", "origin": "external" }
  ],
  "nextCursor": "bTFfMDI"
}
Boundary in one sentence. Can only read this plugin's sessions; contentLimit truncates message bodies, and truncation is marked with contentTruncated.

2How data flows

  1. Call: the plugin passes sessionId (optionally with limit / cursor / order / contentLimit).
  2. Validate: the session must belong to this plugin and the parameters must be valid; otherwise PERMISSION_DENIED / NOT_FOUND / INVALID_ARGUMENT.
  3. Execute: the host pages through messages by cursor, truncating bodies per contentLimit and flagging them.
  4. Return: items + nextCursor, ordered per order.
DirectionContent
plugin → hostSession id plus pagination / ordering / truncation parameters.
host → pluginMessage page { items, nextCursor? }.

4What is not provided

Cannot read other plugins' sessions; contentLimit may truncate message bodies.
