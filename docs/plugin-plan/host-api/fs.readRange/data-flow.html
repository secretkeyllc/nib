1Interface contract

pi.fs.readRange(pathFromRoot: string, byteOffset: number, length: number, grantId?: string): Promise<PluginFsRange>

Reads a bounded byte range from a file. Permission: —

Input

FieldTypeRequiredDescription
pathFromRootstringYesRoot-relative path; subject to read-scope and denylist rules.
byteOffsetnumberYesStarting byte offset (the parameter is byteOffset, not offset).
lengthnumberYesNumber of bytes to read; the range is bounded.
grantIdstringNoUsed only in the dropped-file grant scenario.

Output

FieldTypeDescription
bytesUint8ArrayThe bytes read.
totalSizenumberTotal file size in bytes, to tell whether the end has been reached.

Input example

const head = await pi.fs.readRange("logs/app.log", 0, 4096);

Output example

// bytes is a Uint8Array (illustrative here); totalSize is the file's total byte count
{ "bytes": <Uint8Array 4096 字节>, "totalSize": 946176 }
Boundary in one line. No whole large files; the parameter is byteOffset, not offset.

2How data flows

  1. Call: the plugin passes path, byteOffset, length; dropped files may carry a grantId.
  2. Validate: the path is checked against read scope and the denylist; byteOffset / length must be numbers.
  3. Execute: the host reads only that byte range, never loading the whole file.
  4. Return: bytes and totalSize are returned to the plugin.
DirectionContent
plugin → hostPath + start offset + length (optional grantId).
host → pluginByte range bytes + total file size totalSize.
