1Interface contract

pi.fs.readText(pathFromRoot: string): Promise<string>

Reads the full UTF-8 contents of a text file under the rules root. Permission: —

2How data flows

  1. Call: the plugin passes a root-relative path to the host.
  2. Validation: the path is normalized to forward slashes and any leading / is stripped; paths containing .. or hitting the deny list (.git, .env, etc.) are rejected outright; access outside the read scope declared in manifest.fs falls back to user confirmation.
  3. Execution: the host reads the entire file and decodes it as UTF-8.
  4. Return: the full contents are returned to the plugin as a string, with no write side effects.

4What it does not provide

No absolute paths or .. escapes; no chunking.

Host guarantees / accepted costs: Host guarantee: paths are restricted to the declared scope. Accepted cost: out-of-scope content cannot be read silently.
