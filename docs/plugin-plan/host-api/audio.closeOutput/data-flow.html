1API contract

pi.audio.closeOutput(streamId: string): Promise<void>

Closes a playback session and discards audio still queued and unplayed in it (permission: —).

Input

FieldTypeRequiredDescription
streamIdstringYesThe playback session id returned by openOutput.

Output

FieldTypeDescription
(return value)Promise<void>No data.

Input example

pi.audio.closeOutput("out-8c11d0")

Output example

// no return value
Boundary in one sentence. The close takes effect immediately; it does not wait for or guarantee that the queue finishes playing.

2How data flows

  1. Call: pi.audio.closeOutput(streamId).
  2. Validation: the host checks permission (PERMISSION_DENIED) and that the session exists (NOT_FOUND).
  3. Execution: closes the session and discards audio still queued and unplayed.
  4. Return: resolves and the session is released; closing does not wait for playback to drain.
