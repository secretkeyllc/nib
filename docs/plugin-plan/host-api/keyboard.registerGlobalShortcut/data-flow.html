1API contract

pi.keyboard.registerGlobalShortcut(input: { id: string; accelerator: string; command: string }): Promise<PluginGlobalShortcut>

Bind a system-wide accelerator to a command from this plugin; the host owns the binding and checks for conflicts. Permission: —.

Input

fieldtyperequirednotes
idstringYesThe entry id, unique within this plugin; registering the same id again replaces its accelerator.
acceleratorstringYesThe accelerator string, for example CommandOrControl+Shift+X.
commandstringYesThe id of the command to trigger, which must already be registered through commands.register.

Output

fieldtypenotes
idstringEchoes the entry id.
acceleratorstringEchoes the accelerator string.
commandstringEchoes the command id.
registeredbooleanfalse means the accelerator is held by the system or another owner and registration did not succeed.
errorstring?The reason registration failed; present only on failure.

Input example

{ "id": "quick-open", "accelerator": "CommandOrControl+Shift+X", "command": "demo.hello.open-panel" }

Output example

{
  "id": "quick-open",
  "accelerator": "CommandOrControl+Shift+X",
  "command": "demo.hello.open-panel",
  "registered": true
}
Boundary in one sentence. It can only bind commands from this plugin; when an accelerator is taken it never grabs it back, the result is registered: false, and another key is the only option. No keyboard hooks and no raw key stream.

2How data flows

  1. The plugin submits { id, accelerator, command }.
  2. Validate: command must already be registered, otherwise the call is rejected (INVALID_ARGUMENT); an unsupported platform yields UNSUPPORTED.
  3. The host registers the accelerator with the OS through Electron globalShortcut, and it lasts until it is unregistered or the plugin unloads; default entries declared in contributes.globalShortcuts are also attempted automatically after load.
  4. The Promise resolves to PluginGlobalShortcut: failures are not thrown, they return registered: false with the reason in error (codes in section 3), and a rejected re-registration keeps the original binding.
  5. When the accelerator fires, the host runs the run of the command named by command.

4What is not provided

No keyboard hooks and no raw key stream; an accelerator already taken by the system or the host is never claimed.

Host guarantees / accepted costs: Host guarantee: no key-event stream is exposed. Accepted cost: a conflict is never grabbed back, so another key is the only option.
