1API contract

pi.fs.writeText(pathFromRoot: string, content: string): Promise<void>

Create or overwrite a path under the rules root with text. Permission: — (writes are constrained by fs.write and the declared write scope)

Input

fieldtyperequirednotes
pathFromRootstringYesA path relative to the rules root (forward slashes, no leading /, no ..); it must fall inside the write scope declared by manifest.fs, and that scope may not cover the whole root.
contentstringYesThe complete text to write, replacing the file; there is no append mode.

Output

fieldtypenotes
(return value)voidNo data; the Promise resolving means the write completed.

Input example

await pi.fs.writeText("reports/周报.md", "# 周报\n\n本周完成插件沙箱梳理。");

Output example

// 无返回（void）；resolve 即写入成功
Boundary in one sentence. No append mode, so a large file is rewritten whole; no binary writes; a whole-tree write scope never passes validation.

2How data flows

  1. Call: the plugin passes a root-relative path and the full text.
  2. Validate: fs.write is required; once normalized the path may not contain .., may not hit the denylist, and must fall inside the declared write scope (the scope may not be the whole root, which manifest validation rejects outright).
  3. Execute: the host creates or overwrites that file inside the scope and writes the text.
  4. Return: resolving means done, with no data.
directioncontent
plugin → hostThe root-relative path plus the full text.
host → pluginNo data (success or failure only).
host → systemWrites the file to disk under the workspace (or the userSelected root).

3Error handling

caseresultcode
No fs.write, or the path is outside the declared write scopeWrite refusedPERMISSION_DENIED
A parameter is missing or mistyped (for example a non-string content)Call refusedINVALID_ARGUMENT

4What is not provided

No append-mode API, no binary writes, and a whole-tree write scope never passes validation.

Host guarantees / accepted costs: Host guarantee: nothing outside the declared scope can be written. Accepted cost: there is no append mode, so a large file is rewritten whole.
