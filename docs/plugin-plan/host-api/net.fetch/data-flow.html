1API contract

pi.net.fetch(input: { url: string; method?: string; headers?: Record<string, string>; body?: string; timeoutMs?: number }): Promise<{ status: number; headers: Record<string, string>; bodyText: string }>

The host issues one HTTP request on the plugin's behalf and returns the full response (permission: —; outbound access is constrained by the manifest.net.domains allowlist).

Input

FieldTypeRequiredDescription
urlstringYesTarget address; http / https only, and the host must match manifest.net.domains.
methodstringNoHTTP method, e.g. "GET" / "POST".
headersRecord<string, string>NoRequest header key-value pairs; values must be strings.
bodystringNoRequest body text (e.g. serialized JSON); no binary request bodies.
timeoutMsnumberNoTimeout in milliseconds; on expiry without completion the call fails with TIMEOUT.

Output

FieldTypeDescription
statusnumberHTTP status code.
headersRecord<string, string>Response header key-value pairs.
bodyTextstringResponse body text; text form only, no binary response bodies.

Input example

{ "url": "https://api.example.com/v1/notes", "method": "POST", "headers": { "Content-Type": "application/json" }, "body": "{\"title\":\"会议纪要\"}", "timeoutMs": 10000 }

Output example

{ "status": 200, "headers": { "content-type": "application/json" }, "bodyText": "{\"ok\":true,\"id\":42}" }
Boundary in one sentence. Only hosts declared in manifest.net.domains are reachable; an empty domain list means no outbound access at all, and host proxy keys are never exposed.

2How data flows

  1. Call: the plugin process passes in { url, method?, headers?, body?, timeoutMs? }.
  2. Validation: URL must be http / https only; the hostname must match manifest.net.domains (entries are bare hostnames or *.suffix; ports / paths / a bare * are not accepted), otherwise rejected with PERMISSION_DENIED.
  3. Execution: the host issues the request on the plugin's behalf; if not completed within timeoutMs, it fails.
  4. Return: { status, headers, bodyText } delivered in one shot; no streaming responses, no progress callbacks.
DirectionContent

4What is not provided

An empty domain list allows no outbound access at all; host proxy keys are not exposed.

Host guarantees / accepted costs: Host guarantee: access stays within the declared domains. Accepted cost: with no declared domains, outbound access is impossible.
