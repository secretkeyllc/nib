1API contract

pi.browser.setBounds(hole: { x: number; y: number; width: number; height: number }): Promise<unknown>

Sets the rectangular area of the guest page inside the host panel. Permission: —.

Input

Boundary in one sentence. The rectangle is positioned only within this plugin's panel; the guest-page boundary is limited to the calling plugin's view.

2How data flows

  1. Call: The plugin calls pi.browser.setBounds({ x, y, width, height }).
  2. Validation: The host checks, per the SDK types, that all four numeric fields (hole) are present.
  3. Execution: The host positions this plugin's guest page into the given rectangle.
  4. Return: The Promise resolves with the result; the binding becomes invalid after the plugin is unloaded and no further operations are possible.
DirectionContent
plugin → hostTarget rectangle ({ x, y, width, height }).
host → pluginPromise result (shape is implementation-defined).

4What is not provided

Cannot escape the guest-page boundary; cannot obtain session credentials for arbitrary sites; content security policy and isolation still apply.

Host guarantee / accepted cost: Host guarantee: the guest-page boundary is limited to the calling plugin's view. Accepted cost: CDP calls outside the allowlist are unavailable.
