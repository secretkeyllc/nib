1Interface contract

pi.fs.list(pathFromRoot: string): Promise<PluginFsEntry[]>

Lists the entries under one directory (sorted by name), for lazy-loading a directory tree. Permission: —

Inputs

FieldTypeRequiredDescription
pathFromRootstringYesRoot-relative directory path; lists direct children only, no recursion.

Outputs

FieldTypeDescription
(return value)PluginFsEntry[]Array of entries sorted by name; element structure below.
namestringEntry name (file or directory name).
pathstringRoot-relative path, usable directly with fs.readText / fs.list.
isDirectorybooleanWhether the entry is a directory.
sizenumberFiles only: size in bytes (omitted for directories).
mtimeMsnumberFiles only: modification time in Unix epoch milliseconds (omitted for directories).

Input example

const entries = await pi.fs.list("src");

Output example

[
  { "name": "index.ts", "path": "src/index.ts", "isDirectory": false, "size": 1024, "mtimeMs": 1739462400000 },
  { "name": "utils", "path": "src/utils", "isDirectory": true }
]
Boundary in one sentence.Directories are always listed so the tree stays navigable; files are filtered by the read scope; no recursion — use fs.glob for a whole tree.

2How data flows

  1. Call: the plugin passes a root-relative directory path.
  2. Validation: after normalization the path must not contain .. nor hit the deny list; the directory must be accessible.
  3. Execution: the host reads one level of the directory — directory entries are always listed (keeping the tree navigable), file entries are filtered by the read scope declared in manifest.fs, and heavy/protected directories are skipped.
  4. Return: the sorted array of entries is returned to the plugin.
DirectionContent
plugin → hostRoot-relative directory path.
host → pluginThe sorted PluginFsEntry[].
