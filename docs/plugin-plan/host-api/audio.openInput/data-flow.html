1API contract

pi.audio.openInput(options?: PluginAudioOpenInputOptions): Promise<PluginAudioInputSession>

Opens a background microphone capture stream and returns session metadata (permission: —).

Input

Input is the optional object PluginAudioOpenInputOptions, which can be omitted entirely (omitting it means the system default input).

FieldTypeRequiredNotes
deviceIdstringNoDevice id from getInputDevices; omit to use the system default input.
sampleRatenumberNoDesired sample rate.
channelsnumberNoNumber of channels.
echoCancellationbooleanNoEcho cancellation.
noiseSuppressionbooleanNoNoise suppression.
autoGainControlbooleanNoAutomatic gain control.

Output

FieldTypeNotes
streamIdstringSession id; closeInput closes with it, and streamId in frame events matches it.
sampleRatenumberSample rate actually in effect.
channelsnumberNumber of channels actually in effect.
deviceIdstringOptional; the device id actually opened.
labelstringOptional; display name of the device actually opened.

Input example

{ "deviceId": "", "sampleRate": 16000, "channels": 1, "echoCancellation": true }

Output example

{ "streamId": "in-3f9a2c", "sampleRate": 16000, "channels": 1, "label": "默认 - 麦克风 (Realtek Audio)" }
Boundary in one sentence. Each plugin has exactly one input stream at a time; what you get is session metadata, not a MediaStream, and OS device paths are not exposed.

2How data flows

  1. Call: pi.audio.openInput(options?); the argument can be omitted entirely.
  2. Validation: the host checks the permission (PERMISSION_DENIED when not granted) and argument validity (INVALID_ARGUMENT).
  3. Execution: the host opens the device and holds it on the plugin's behalf; each plugin may have only one input stream at a time.
  4. Return: resolves with the session { streamId, sampleRate, channels, deviceId?, label? }; frames then arrive via onInputFrame.
  5. Lifecycle: when the plugin is disabled / unloaded / crashes, the host stops the capture immediately.
DirectionContent
plugin → hostOpen request (device id, sample rate / channel count, echo-cancellation / noise-suppression / auto-gain preferences).
host → pluginSession metadata (streamId plus the parameters actually in effect).
host → systemOpens the selected system input device.
