1Interface contract

pi.session.importBatch(input: PluginSessionBatchImportInput): Promise<PluginSessionBatchImportResult>

Imports multiple external sessions sharing one source in a batch, returning per-item results plus counts. Permission: —.

Input

FieldTypeRequiredDescription
sourcestringYesSource namespace shared by the whole batch; must be declared in the manifest's sessionSources.
sessionsArray<Omit<PluginSessionImportInput, "source">>YesArray of sessions; element structure is the pi.session.import input minus source.
mode"skip" | "fail"NoPer-item failure policy: skip skips the item and continues, fail fails the whole batch.

Output

FieldTypeDescription
resultsarrayPer-item results. Element structure: externalId, sessionId (null on failure), status ("imported"|"skipped"|"failed"), errorCode?, errorMessage?.
importednumberNumber imported successfully.
skippednumberNumber skipped.
failednumberNumber failed.

Input example

{
  "source": "wechat-export",
  "mode": "skip",
  "sessions": [
    {
      "externalId": "wx-2026-0212-01",
      "title": "React 迁移讨论",
      "createdAt": "2026-02-12T08:30:00.000Z",
      "updatedAt": "2026-02-14T21:05:00.000Z",
      "messages": [ { "role": "user", "content": "帮我看看这个报错", "createdAt": "2026-02-12T08:30:00.000Z" } ]
    }
  ]
}

Output example

{
  "results": [
    { "externalId": "wx-2026-0212-01", "sessionId": "imp_9f3a2c", "status": "imported" },
    { "externalId": "wx-2026-0212-02", "sessionId": null, "status": "failed", "errorCode": "INVALID_ARGUMENT", "errorMessage": "消息格式非法" }
  ],
  "imported": 1,
  "skipped": 0,
  "failed": 1
}
Boundary in one line. No transactional rollback: after mode: "fail" aborts, already-imported items remain.

2How data flows

  1. Call: the plugin submits source + session array + mode.
  2. Validate: source must be declared; an invalid top-level input fails outright (codes as in import).
  3. Execute: each item goes through session.import validation and persistence; a failed item is skipped or aborts according to mode.
  4. Return: per-item status (failed items carry errorCode / errorMessage) plus imported / skipped / failed counts.
DirectionContent
plugin → hostA batch of external sessions (shared source) and the failure policy.
host → pluginPer-item result array plus the three counts.
