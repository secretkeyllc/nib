Self-managed overlay · Index

Full-screen dialogs and corner overlays are self-managed by the plugin: no slot and no registration. Four hard limits apply, and Esc never closes a security layer.

Summary

  • No slot, no registration, self-managed: the plugin draws it inside its own component with position: fixed.
  • The four hard limits: draw inside its own component; disappear on unload; never stack above a host security layer; among plugins the later-opened sits on top, and the host does not arbitrate.
  • Esc never closes a security layer; closing happens only through an explicit UI action (the close button).
